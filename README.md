# jamisonhill/homebrew-tap

Homebrew tap for my macOS apps.

```bash
brew tap jamisonhill/tap
```

## Casks

| Cask | Description |
| ---- | ----------- |
| [`claude-launcher`](https://github.com/jamisonhill/claude-launcher) | A native macOS GUI for launching Claude Code sessions in Terminal |

```bash
brew install --cask jamisonhill/tap/claude-launcher
```

Casks here are generated by each app's own `publish.sh`, so the version and
checksum always match a real, notarized release. Editing them by hand will be
overwritten on the next release.
